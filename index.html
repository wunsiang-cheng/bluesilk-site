bluesilk
GitHub PyPI

A minimal personal AI agent.

Any tool-calling model on OpenRouter, reached through your private Telegram chat, a built-in web console, or both. One conversation, whichever channel you pick up.

$ uv tool install bluesilk

What it does

  • One conversation

    Telegram and the web console share a single thread. The reply goes to the channel you wrote on.

  • Memory and skills

    Persistent memory, reusable skills, custom tools and conversation history, all as plain files under ~/.bluesilk/.

  • Shell and jobs

    Shell access, file transfer, image understanding and background jobs that keep running while you talk.

  • Sub-agents

    Up to five helpers, each on its own thread with the same tools. They report to the agent, not to you.

  • Browser and desktop

    Drives a headless Chromium from screenshots. On X11, it can act on the real screen too.

  • MCP servers

    Local stdio or remote Streamable HTTP servers, configured in one JSON file. Tools appear as server__tool.
